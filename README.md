# Paul's KEC Training Guide

Mobile-first Kitchen Exhaust Cleaning field training system for technician onboarding, QA readiness, documentation discipline, and manager sign-off.

## Features

- Technician onboarding modules
- NFPA 96 / ANSI-IKECA awareness language
- Job-site protection checklist
- Chemical and pressure-washing workflow
- Before/after photo documentation checklist
- Deficiency reporting workflow
- QA scorecard
- Quiz with scoring
- Digital sign-off / printable completion record
- Offline-capable PWA files
- GitHub Pages compatible

## Standards Positioning

This is a standards-aware training aid. It does **not** replace official NFPA, IKECA, OSHA, SDS, AHJ, manufacturer, employer, or certification requirements.

Use correct language: **duct collar**, not “duck collar.”

## GitHub Pages Deployment

Upload these files to the repository root:

- `index.html`
- `README.md`
- `manifest.webmanifest`
- `service-worker.js`
- `icon.svg`

Then enable:

`Settings → Pages → Deploy from branch → main → /root`
